# E-Commerce Sales & Profitability Performance Dashboard

**Business Intelligence | Tableau**

## Project Overview
An interactive Tableau project built to analyze e-commerce sales, profitability, order activity, and customer performance.

The project integrates multiple CSV data sources into a structured data model and presents key business insights through interactive dashboards.

## Project Structure
- 7 CSV data sources
- Fact and Dimension data model
- 8 Worksheets
- 2 Interactive Dashboards

## Key Performance Indicators
- Total Profit
- Profit Margin
- Average Order Value (AOV)
- Distinct Orders
- Distinct Customers

## Tools & Techniques
- Tableau
- Data Modeling
- Data Visualization
- Calculated Fields
- Parameters
- Filters
- Dashboard Actions
- Interactive KPI Reporting

## Project Objective
To explore e-commerce business performance, evaluate profitability, and provide interactive insights into sales, orders, and customer activity.

## Project Scope
The dashboards and underlying data model were independently developed using multiple CSV sources, with calculated measures and interactive features designed to support business performance analysis.
